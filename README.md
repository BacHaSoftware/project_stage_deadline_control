## About The Project

<div align="left">
  <a href="https://github.com/BacHaSoftware/project_stage_deadline_control">
    <img src="/bhs_project_stage_deadline/static/description/banner.png" alt="Project Stage Deadline Control">
  </a>
  <div align="center">Project Stage Deadline Control </div>
</div>

Project Stage Deadline Control extends Odoo Project with stage-level control over whether task deadlines are displayed on Kanban cards.

#### Key Features:

🌟 <code>Show Deadline Setting</code>: Configure deadline visibility directly on each task stage.
🌟 <code>Stage-Based Display</code>: Hide the deadline on task cards when the current stage is configured not to show it.

## Getting Started

### Installation

Install module <code>bhs_project_stage_deadline</code>. The Odoo <code>project</code> dependency is installed automatically when required.

<p align="right">(<a href="#readme-top">back to top</a>)</p>


<!-- USAGE EXAMPLES -->
## Usage

Open a project task stage and set the <code>Show Deadline</code> option according to your workflow. Task Kanban cards in that stage display the deadline only when the option is enabled and the task is not completed or canceled.

#### Featured Highlight:

🌟 <code>Easy To Use</code>: You just need to install module and no more configuration is required.
🌟 <code>Flexible Boards</code>: Show deadlines only in stages where schedule visibility helps the project team.
